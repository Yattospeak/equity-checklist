# equity-checklist

Michael Shearn Investment Checklist Analyzer · 麦可席恩投资检查表分析技能

输入 A 股 / 港股上市公司，从**业务、管理层、财务、估值**四个维度进行潜力与估值分析，输出移动端优先的单文件 HTML 报告。

## 快速开始

```bash
pip install -r scripts/requirements.txt

# 一键出报告
python3 scripts/analyze.py "贵州茅台" -o ./reports
```

也可分三步调用，便于在打分阶段介入人工判断：

```bash
python3 scripts/collect.py "贵州茅台" -o metrics.json
python3 scripts/auto_score.py metrics.json -o scores.json
python3 scripts/render.py metrics.json --scores scores.json -o report.html
```

产出为单文件 HTML，CSS 全内联、零外部依赖，可直接在微信内置浏览器打开或用小程序 `<web-view>` 加载。

## 评分模型

| 维度 | 权重 | 自动化可信度 |
|------|:---:|:---:|
| 业务质量 | 30% | 中（代理指标） |
| 管理层 | 25% | 低（仅资本配置可量化） |
| 财务质量 | 25% | 高（纯数据） |
| 估值 | 20% | 中 |

**评级档位（三档）**：

| 综合分 | 评级 |
|:---:|:---:|
| ≥ 3.8 | 🟢 **优** |
| 3.0 – 3.8 | 🟡 **中** |
| < 3.0 或触发硬性闸门 | 🔴 **低** |

硬性闸门：任一维度 < 3.0 时评级直接降为「低」。

输出评级而非买卖建议——描述的是企业质量与估值的综合吸引力，不是交易指令。

完整评分标准见 [`检查表评估模型.md`](检查表评估模型.md)，技能定义见 [`SKILL.md`](SKILL.md)。

## 数据源

均为免登录公开接口：腾讯行情、新浪财报、东方财富数据中心、巨潮资讯、同花顺。无需 API Key。

## 市场覆盖

**A 股**：完整支持业务 / 管理层 / 财务 / 估值四维。

**港股**：利润表与资产负债表已接入（东财 HKF10，可回溯约 9 个年度），
业务 / 财务 / 估值维度可正常评分。以下三项无免登录公开源，按**缺失**处理
（中性计分，绝不按 0 分处理）：

- 现金流量表 → OCF/净利、自由现金流等指标缺失
- 分红、股东户数 → 股息率、派息率、资本配置分红项缺失
- 公告 → 回购 / 增持 / 再融资等治理信号无法自动核查

## 使用限制

- 港股无现金流量表源，盈利含金量（OCF/净利）无法评估——财务维度会略偏保守
- 港股采集耗时约 35–40s（A 股约 8s）：数据源为纵表且单页有行数上限，需分期拉取
- 银行 / 保险 / 证券等金融股会自动禁用实业口径指标，建议改用专用框架复核
- 历史估值分位（PE / PB 10 年分位）未自动计算，需人工补充
- 管理层诚信度、减持、监管处罚等项无法自动核查，一律给中性分并标注「待人工核查」
- 数据源为公开免费源，对频率敏感，脚本已内置 1.2s 限流与重试
